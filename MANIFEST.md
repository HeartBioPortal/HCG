# Repository Manifest

## Code

- `src/hcg/`: CLI, scraper, sync orchestration, OpenAI extraction, image preparation, schemas, and release builder.
- `src/hcg/scraper/`: ACC/AHA and ESC guideline discovery and download helpers.
- `tests/`: parser, sync, path, extraction, and release-builder coverage.

## Inputs

- `data/AHA-ACC-NEW/`: refreshed local AHA/ACC guideline PDF corpus.
- `data/ESC-NEW/`: refreshed local ESC guideline PDF corpus.
- `data/reference/gene_names.json`: gene-symbol reference used during extraction normalization.

Guideline PDFs are third-party source documents. Redistribution rights require source-specific review.

## Generated outputs

- `data/prepared_images/`: generated page-image directories and manifests. These are intentionally ignored by git and should be regenerated locally.
- Extracted page JSON outputs: generated by `hcg extract` or `hcg sync` when an API key is available.
- Release JSON artifacts: generated by `hcg build-release` after extraction validation.

## Release metadata and documentation

- `README.md`: overview, setup, usage, HBP 3.0 role, release notes, and safety/privacy cautions.
- `GUIDELINE_SOURCES.tsv`: source-document metadata and license notes.
- `OUTPUT_MANIFEST.tsv`: output-family metadata.
- `PROVENANCE_SCHEMA.md`: provenance fields expected in guideline extraction outputs.
- `RELEASE_NOTES.md`: HBP 3.0 manuscript release notes.
- `CITATION.cff` and `.zenodo.json`: citation and archive metadata.
- `scripts/generate_checksums.sh`: checksum helper for release-relevant static files.

## Do not include without review

- API keys or credentials
- protected or controlled human data
- long guideline excerpts when redistribution rights are unclear
- raw or derived source documents not covered by release permissions
- generated image or JSON bulk outputs unless intended and permitted for archive
