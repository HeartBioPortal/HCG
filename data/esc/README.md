# ESC Dataset

This directory is reserved for ESC guideline scraping and extraction outputs.

- `source_pdfs/`
  Downloaded ESC guideline PDFs from the official ESC clinical practice guideline pages.
- `openai_outputs/`
  Page-level JSON outputs and aggregated document JSON generated by `hcg extract` or `hcg sync`.
- `scraper_manifest.json`
  Created after the scraper runs. Tracks discovered guideline pages, download URLs, local PDF paths, and status.
- `scraper.log`
  Scraper log file for ESC discovery and downloads.

The repository currently ships the ACC/AHA extraction outputs. Run `hcg sync --datasets esc ...` to populate the ESC dataset.
